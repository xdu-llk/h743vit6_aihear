# AI Hear 国赛版最终硬件引脚表

> 主控：鹿小班 STM32H743VIT6 V2.0，HSE=25MHz。H2、H3均为开发板两侧的2x20P扩展排针。
>
> 下表是PCB和装配的唯一接线依据。所有模块必须共地；没有列为连接的模块引脚一律不得自行接入H7。

## 1. 开发板电源

| 电源 | 开发板位置 | 用途 |
|---|---|---|
| 5V | H3-1、H3-2 | MQ-135、GP2Y1014AU0F的PM2.5 V2.1适配板 |
| 3.3V | H3-3、H3-4 | INMP441、ESP-01、DHT11、蜂鸣器 |
| GND | H2-1、H2-2 | 全系统公共地 |
| USB-C 5V | 开发板USB-C | 整机唯一电源入口 |

ST-Link只连接`SWDIO`、`SWCLK`、`GND`和`3.3V`参考电压；不得连接ST-Link的`5V`给整机供电。实测ST-Link 5V不足以可靠驱动当前整机负载，会使颗粒物模块输出失效。

## 2. INMP441（1x6）

| INMP441引脚 | 最终连接 | 开发板位置 | 说明 |
|---|---|---|---|
| SCK | PD0 / SAI3_SCK_A AF6 | H3-15 | I2S位时钟 |
| WS | PD4 / SAI3_FS_A AF6 | H3-18 | I2S左右声道时钟 |
| L/R | GND | 公共地 | 固定选择当前训练声道 |
| SD | PD1 / SAI3_SD_A AF6 | H3-16 | I2S音频数据输入 |
| VDD | 3.3V | H3-3或H3-4 | 禁止接5V |
| GND | GND | H2-1或H2-2 | 公共地 |

## 3. ESP-01 / ESP8266（2x4）

| ESP-01引脚 | 最终连接 | 开发板位置 | 说明 |
|---|---|---|---|
| VCC | 3.3V | H3-3或H3-4 | 禁止接5V |
| GND | GND | H2-1或H2-2 | 公共地 |
| TX | PA1 / UART4_RX AF8 | H2-34 | ESP TX -> H7 PA1 |
| RX | PA0 / UART4_TX AF8 | H2-33 | ESP RX <- H7 PA0 |
| EN / CH_PD | 3.3V | H3-3或H3-4 | 常高使能 |
| RST | PA2 / GPIO输出 | H2-31 | H7低电平复位ESP |
| GPIO0 | KEY2按键后接GND | 不接H7 | 长按5秒清除配网；上电时按住会进入下载模式 |
| GPIO2 | NC | 不连接 | 保持模块默认上拉 |

ESP必须使用可拔2x4插座。烧录时拔下ESP，用外部CH340单独连接；正常运行时不在载板上连接CH340。

## 4. DHT11三针模块（1x3）

| DHT11引脚 | 最终连接 | 开发板位置 | 说明 |
|---|---|---|---|
| VCC | 3.3V | H3-3或H3-4 | 按模块丝印确认针序 |
| DATA / OUT | PE7 / GPIO | H2-21 | 单总线数据 |
| GND | GND | H2-1或H2-2 | 公共地 |

## 5. MQ-135四针模块（1x4）

| MQ-135引脚 | 最终连接 | 开发板位置 | 说明 |
|---|---|---|---|
| VCC | 5V | H3-1或H3-2 | 模块加热器供电 |
| GND | GND | H2-1或H2-2 | 公共地 |
| DO | NC | 不连接 | 不使用数字比较器输出 |
| AO | PA3 / ADC12_INP15 | H2-32 | 只读取模拟量；不得制造高浓度刺激 |

## 6. GP2Y1014AU0F + PM2.5 V2.1适配板（1x4）

| 适配板引脚 | 最终连接 | 开发板位置 | 说明 |
|---|---|---|---|
| VCC | 5V | H3-1或H3-2 | 适配板供电 |
| GND | GND | H2-1或H2-2 | 公共地 |
| AO | PC1 / ADC123_INP11 | H3-14 | 适配板模拟输出 |
| ILED | PD7 / GPIO输出 | H3-21 | 控制LED采样脉冲；软件比较开灯前/开灯后的AO差值 |

GP2Y1014AU0F金属传感器到适配板继续使用原装6芯线，不在载板上拆分这6根内部连接。

## 7. 共阴RGB LED模块（1x4）

|---|---|---|---|

| B | PB3 / GPIO输出 | H3-22 | 蓝色通道 |
| 共阴 / GND | GND | H2-1或H2-2 | 模块自带限流电阻 |

## 8. 无源蜂鸣器模块（1x3）

| 蜂鸣器引脚 | 最终连接 | 开发板位置 | 说明 |
|---|---|---|---|
| VCC | 3.3V | H3-3或H3-4 | 使用现成驱动模块 |
| I/O / SIG | PB0 / TIM3_CH3 AF2 | H2-23 | PWM旋律，当前模块低电平有效 |
| GND | GND | H2-1或H2-2 | 公共地 |

## 9. 配网按键

| 按键 | 一端 | 另一端 | 说明 |
|---|---|---|---|
| KEY2 | ESP GPIO0 | GND | 长按5秒配网；不接H7 |

载板不设置H7硬件复位按键；需要复位时使用开发板现有复位方式。

## 10. CH340调试串口（外接，不装入最终载板）

| CH340引脚 | 最终连接 | 开发板位置 | 说明 |
|---|---|---|---|
| RXD | PA9 / USART1_TX AF7 | 调试座TXD或H3-10 | CH340 RXD <- H7 PA9 |
| TXD | PA10 / USART1_RX AF7 | 调试座RXD或H3-9 | CH340 TXD -> H7 PA10 |
| GND | GND | 开发板GND | 必须共地 |
| VCC / 3.3V / 5V | NC | 不连接 | CH340不向整机供电 |

## 11. ST7789 240x240（厂家DISPLAY FPC直连）

使用厂家配套灰色软排线连接开发板10触点、0.5mm间距DISPLAY FPC座。下表编号是开发板FPC座编号，不是模块端镜像编号；不要在载板PCB上重复布线。

| 开发板DISPLAY座脚 | 屏幕信号 | H7最终连接 | 说明 |
|---:|---|---|---|
| 1 | GND | GND | 电源地 |
| 2 | SCK | PE12 / SPI4_SCK AF5 | SPI时钟 |
| 3 | GND | GND | 电源地 |
| 4 | BL | PD15 / GPIO输出 | 高电平开启背光 |
| 5 | DC | PE15 / GPIO输出 | 命令/数据选择 |
| 6 | CS | PE11 / GPIO软件片选 | 低电平选中屏幕 |
| 7 | MOSI / SDI | PE14 / SPI4_MOSI AF5 | SPI显示数据 |
| 8 | GND | GND | 电源地 |
| 9 | VCC | 3.3V | 屏幕供电 |
| 10 | VCC | 3.3V | 屏幕供电 |
| 11 | 座体固定焊脚 | GND | 非软排线触点 |
| 12 | 座体固定焊脚 | GND | 非软排线触点 |

该FPC屏没有RES、MISO或SDO。必须断电后按厂家安装图的触点方向插入并锁紧座扣，不能随意翻面插入。

| 1 | VCC | 3.3V | 模块供电 |
| 2 | VCC | 3.3V | 模块供电 |
| 3 | VCC | 3.3V | 模块供电 |
| 4 | GND | GND | 电源地 |
| 5 | GND | GND | 电源地 |
| 6 | SCCB_SDA | PB9 / 软件开漏 | 摄像头寄存器数据 |
| 7 | SCCB_SCL | PB8 / 软件开漏 | 摄像头寄存器时钟 |
| 8 | GND | GND | 电源地 |
| 9 | RESET | PC4 / GPIO输出 | 低电平复位摄像头 |
| 10 | FLASH / LED | PA5 / GPIO输出 | 高电平点亮补光 |
| 11 | PWDN | PD14 / GPIO输出 | 高电平进入掉电模式 |
| 12 | HREF / HSYNC | PA4 / DCMI_HSYNC AF13 | 行同步 |
| 13 | VSYNC | PB7 / DCMI_VSYNC AF13 | 帧同步 |

| 15 | D1 | PC7 / DCMI_D1 AF13 | 图像数据位1 |

## 13. 不得复用的开发板引脚

| 板载功能 | 已占用引脚 |
|---|---|
| W25Q QSPI Flash | PB2、PB6、PD11、PD12、PD13、PE2 |
| MicroSD | PC8、PC9、PC10、PC11、PC12、PD2 |
| USB | PA11、PA12 |
| SWD | PA13、PA14 |
| HSE / LSE | PH0、PH1、PC14、PC15 |
| DISPLAY / CAMERA FPC | 第11、12节列出的全部H7引脚 |

载板不得设置TFT或OV2640排母，也不得重复布置SPI4/DCMI信号。PCB必须给开发板两个FPC座、USB-C和ST-Link调试座留出插拔空间；外壳最终开孔和固定柱位置以到货实物1:1复核为准。
