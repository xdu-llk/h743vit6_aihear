# AI Hear 国赛版硬件引脚与载板 PCB 方案

> 冻结日期：2026-07-31
>
> 适用主板：鹿小班 STM32H743VIT6 V2.0
>
> 目标：只采购裸 PCB，只焊排母、排针和按键；传感器均使用现成模块。

## 1. 结论

1. OV2640 直接使用 H7 开发板自带的 CAMERA FPC，不在载板上重新布 8 位 DCMI 总线。
2. INMP441 必须从当前 SAI1 的 `PE4/PE5/PE6` 迁移到 SAI3 的 `PD4/PD0/PD1`，否则与摄像头 D4/D6/D7 冲突。
3. 不能改用 `PD11/PD12/PD13` 的 SAI2：这三根线已连接板载 W25Q Flash，会产生实际电气冲突。
4. ST7789 使用开发板 DISPLAY FPC 和 SPI4：`PE11/PE12/PE14/PE15/PD15`，载板不再设置 TFT 排母。
5. DHT11 从 `PD0` 迁移到 `PE7`；`PD0` 留给 SAI3 时钟。
6. MQ-135 只读取 AO并按用户最终演示选择直连 `PA3/ADC12_INP15`；DO 不接。厂家资料标称AO高浓度下可到约4V，因此这是已知风险的受控演示接法，不是安全量产接法。
7. GP2Y1010 适配板的 AO 接 `PC1/ADC123_INP11`，ILED 接 `PD7`。
8. 摄像头 SCCB 占用 `PB8/PB9`；RGB 蓝色使用空闲的 `PB3`，与 `PB4/PB5` 位于同侧相邻排针，便于PCB布线。
9. KEY1 连接开发板 V2.0 调试排针上的 `RST` 与 `GND`，实现真正硬件复位；KEY2 连接 ESP-01 `GPIO0` 与 GND。
10. 载板的 5V、3.3V 和 GND 均从 H7 开发板排针取得，USB-C 仍是唯一电源入口。

## 2. 当前烧录版本与最终版

### 2.1 当前过渡测试固件

2026-07-31 已烧录的阶段1固件用于回归原有功能。此时 TFT、OV2640、MQ-135 和 GP2Y1010 尚未加入；RGB蓝灯已经迁移，不能再接回PB8。

阶段2.1固件已经加入 ST7789 与DHT环境状态机，完成全量编译、烧录和无屏回归。TFT未连接时，H7启动、音频推理、DHT每2秒云端上报以及MQTT双向控制均正常。实测环境报文间隔约2.01秒，设备ID、有效标记与状态字段完整。屏幕到货后的板测只连接 DISPLAY FPC 的 TFT；新增传感器按MQ-135、GP2Y1010的顺序接入，OV2640保持最后。

阶段2.2软件已加入 PA3/ADC1 的 MQ-135 相对指数监测：切换到PA3后丢弃首样本、1秒采样、16次ADC均值、60秒最低预热、动态稳定基线、EMA滤波、5次异常/恢复确认与3次故障确认。动态基线以30秒为一个窗口，窗口内峰峰值和相邻窗口均值变化均不超过8%才算连续稳定；两个稳定窗口后就绪，不稳定则重新累计，最早约120秒就绪。2026-07-31实板已多次完成动态基线并进入normal；原始基线随预热和环境变化，不在软件或报告中固化某次读数。受控气体刺激告警尚未测试。

阶段2.3软件已加入 PC1/ADC1 + PD7/ILED 的 GP2Y1010/GP2Y1014 适配板支持。实现以本地厂家资料为准：ILED高有效，开启280μs后采样、再保持40μs；适配板含1:10分压，AO按11倍还原，固件不宣称未经标定的μg/m³，只上报自动基线相对指数。实板发现单脉冲采样存在明显尖峰，现每秒按约10ms周期连续采9个脉冲取中值，再做5点跨秒中值、10点基线、EMA与5次确认；持续异常约7-10秒确认，孤立尖峰不告警。双层中值版在未焊排针的临时接线保持不动时完成连续约110秒静态实板回归，期间PM保持normal、无误报，MQ动态基线完成，音频推理与整机运行正常。PM持续异常与恢复已通过宿主测试；实板事件曾完整触发本地状态，并在公网观察到设备定向`particle_high`与`particle_high_recovered`。按当前推进决定不再做真实烟尘刺激，焊接排针后的长期稳定性仍待复测。

阶段2.4已加入OV2640完整软件流程：SCCB探测、DCMI/DMA2抓取240x240 RGB565与320x240 JPEG、补光灯短时控制、60KB JPEG硬上限、CRC32/Base64分片和15秒整次上传上限。哭声告警先发布再抓拍，环境告警不抓拍。无摄像头实板上已验证`unavailable`快速返回，随后音频推理、MQ-135和GP2Y1010继续运行；真实方向、颜色、JPEG大小和补光效果必须等模块到货验证。Android桥接模拟已用320x240真实JPEG验证照片、失败状态和375x812布局。ESP照片转发需要bridge-v5，两台当前实板仍是v4。

| 模块 | 当前接线 | 说明 |
|---|---|---|
| INMP441 | SCK→PD0，SD→PD1，WS→PD4，L/R→GND | 已迁移到 SAI3 |
| DHT11 | DATA→PE7 | 已迁移，约 2 秒读取一次 |
| OLED | 不连接 | I2C2/OLED不再初始化；PB10/PB11保持空闲 |
| RGB | R→PB4，G→PB5，B→PB3，共阴→GND | 三路仅作GPIO开关，不使用软件PWM |
| 蜂鸣器模块 | I/O→PB0 | 当前告警旋律保持不变 |
| 临时软件按键 | 不连接 | PC4不再初始化，保留给OV2640 RESET；KEY1最终接硬件RST |
| ESP-01 | RX→PA0，TX→PA1，RST→PA2 | UART4，现有链路不变 |
| CH340 | RXD→PA9，TXD→PA10，GND→GND | USART1，115200 8N1；VCC/3.3V/5V 不接 |

TFT首轮板测不连接 OV2640。DHT11 保持每2秒读取并驱动TFT实时指示；高温、低温、高湿、低湿均连续3次越限后确认，恢复使用回差并连续3次确认。传感器连续3次读取失败才进入故障，连续3次有效读取后退出故障。

| ESP-01 | TX | PA1 | UART4_RX, AF8 | H2-34 | 交叉接ESP TX |

| GP2Y1010 | AO | PC1 | ADC123_INP11 | H3-14 | 接适配板AO |
| GP2Y1010 | ILED | PD7 | GPIO推挽输出 | H3-21 | 高电平点亮采样LED |
| INMP441 | SCK | PD0 | SAI3_SCK_A, AF6 | H3-15 | 16kHz、24bit I2S |
| INMP441 | SD | PD1 | SAI3_SD_A, AF6 | H3-16 | 麦克风数据输入 |

| RGB | R | PB4 | GPIO推挽输出 | H3-23 | 共阴模块，自带限流电阻 |
| RGB | G | PB5 | GPIO推挽输出 | H3-24 | 共阴模块，自带限流电阻 |

ST7789和OV2640分别直插开发板DISPLAY/CAMERA FPC，不经过载板H2/H3，也不在PCB上重复布线；其逐脚定义见3.2和第4节。

## 3. 模块排母定义

### 3.1 INMP441，1x6

模块丝印顺序为 `SCK, WS, L/R, SD, VDD, GND`。

| 模块脚 | 连接 |
|---|---|
| SCK | PD0 / SAI3_SCK_A |
| WS | PD4 / SAI3_FS_A |
| L/R | GND，固定选择当前训练和固件使用的声道 |
| SD | PD1 / SAI3_SD_A |
| VDD | 3.3V |
| GND | GND |

### 3.2 ST7789，开发板 DISPLAY FPC

屏幕使用与开发板匹配的蓝白软排线直插 DISPLAY FPC，不在载板上增加 1x8 排母或重新布 SPI 信号。

| DISPLAY FPC脚 | 屏幕信号 | H7连接 | 固件方式 |
|---:|---|---|---|
| 1 | GND | GND | 电源地 |
| 2 | SCK | PE12 | SPI4_SCK, AF5 |
| 3 | GND | GND | 电源地 |
| 4 | BL | PD15 | GPIO推挽输出，背光控制 |
| 5 | DC | PE15 | GPIO推挽输出，数据/命令选择 |
| 6 | CS | PE11 | GPIO软件片选 |
| 7 | MOSI | PE14 | SPI4_MOSI, AF5 |
| 8 | GND | GND | 电源地 |
| 9 | VCC | 3.3V | 屏幕供电 |
| 10 | VCC | 3.3V | 屏幕供电 |
| 11、12 | 固定脚 | GND | FPC座外壳固定脚 |

该屏没有 RES 和 MISO/SDO；不得按普通8针ST7789模块的针序接线。排线插入前必须按开发板和屏幕实物确认触点朝向。

### 3.3 DHT11，1x3

按模块丝印连接 `GND, I/O, VCC`，不得按照片方向猜针序。

| 模块脚 | 连接 |
|---|---|
| GND | GND |
| I/O | PE7 |
| VCC | 3.3V |

模块板已带上拉和指示灯，载板不重复放上拉电阻。

### 3.4 GP2Y1010 适配板，1x4

使用实物适配板丝印 `VCC, GND, AO, ILED`。

| 模块脚 | 连接 |
|---|---|
| VCC | 5V |
| GND | GND |
| AO | PC1 / ADC123_INP11 |
| ILED | PD7 |

金属传感器继续通过原装 6 芯插头连接适配板；载板只安装适配板的 1x4 插座。

### 3.5 MQ-135 模块，1x4

| 模块脚 | 连接 |
|---|---|
| VCC | 5V |
| GND | GND |
| AO | PA3 / ADC12_INP15 |
| DO | NC，不连接 |

厂家资料给出的AO范围是洁净空气约0.1-0.3V、高浓度时约4V，后者超过H7 ADC的3.3V范围。项目根据用户决定不增加分压模块，只在不主动制造高浓度的受控比赛演示中直连；此决定不等于电气安全验证，也不能写成量产接法。

电位器只调 DO 比较阈值，对本项目使用的 AO 没有校准作用。DO为0/5V TTL，不接H7。本项目只输出动态基线相对指数，不宣称 ppm、具体气体浓度或单一气体种类。上电最低预热60秒，之后连续两个30秒窗口的窗口内波动和窗口间漂移均满足8%稳定度才参与环境告警；不稳定时继续显示预热/基线状态。

### 3.6 RGB 模块，1x4

按实物丝印连接：公共阴极接 GND，R/G/B 分别接 PB4/PB5/PB3。模块已有三个限流电阻。

### 3.7 蜂鸣器模块，1x3

按实物丝印 `GND, I/O, VCC` 连接，I/O 接 PB0。默认沿用已验证的 3.3V 供电和低电平触发方式。播放期间固件暂停新的哭声告警判定，停止后再等待短暂安静期，避免蜂鸣器声音反向触发模型。

### 3.8 ESP-01，2x4 可拆插座

| ESP 信号 | 连接 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| EN / CH_PD | 3.3V |
| TX | PA1 / UART4_RX |
| RX | PA0 / UART4_TX |
| RST | PA2 |
| GPIO0 | KEY2，按键另一端接 GND |
| GPIO2 | NC |

ESP 必须可拔下，用外部 CH340 单独烧录。载板不放 ESP 烧录排针和测试焊盘。不要在上电或复位瞬间按住 KEY2，否则 ESP 会进入串口下载模式；日常配网只在固件正常运行后长按 5 秒。

## 4. OV2640 使用开发板 FPC

开发板 CAMERA FPC 已经完成 DCMI、SCCB、电源和补光控制连接，载板不要再复制这些连线。

| CAMERA FPC脚 | 信号 | H7引脚 | 固件方式 |
|---:|---|---|---|
| 1、2、3 | VCC | 3.3V | 摄像头供电 |
| 4、5 | GND | GND | 电源地 |
| 6 | SCCB_SDA | PB9 | 软件SCCB，开漏+上拉 |
| 7 | SCCB_SCL | PB8 | 软件SCCB，开漏+上拉 |
| 8 | GND | GND | 电源地 |
| 9 | RESET | PC4 | GPIO输出，低电平复位 |
| 10 | FLASH / 双补光灯 | PA5 | GPIO输出，高电平点亮 |
| 11 | PWDN | PD14 | GPIO输出，高电平掉电 |
| 12 | HREF / HSYNC | PA4 | DCMI_HSYNC, AF13 |
| 13 | VSYNC | PB7 | DCMI_VSYNC, AF13 |
| 14 | D0 | PC6 | DCMI_D0, AF13 |
| 15 | D1 | PC7 | DCMI_D1, AF13 |
| 16 | D2 | PE0 | DCMI_D2, AF13 |
| 17 | D3 | PE1 | DCMI_D3, AF13 |
| 18 | D4 | PE4 | DCMI_D4, AF13 |
| 19 | D5 | PD3 | DCMI_D5, AF13 |
| 20 | D6 | PE5 | DCMI_D6, AF13 |
| 21 | D7 | PE6 | DCMI_D7, AF13 |
| 22 | PCLK | PA6 | DCMI_PIXCLK, AF13 |
| 23 | NC | 不连接 | 厂家原理图悬空 |
| 24 | GND | GND | 电源地 |
| 25、26 | 固定脚 | GND | FPC座外壳固定脚 |

摄像头模块自带 24MHz 有源晶振，因此不需要 H7 输出 XCLK。`PC4` 原来的 H7 软件按键功能必须删除，因为它已是摄像头 RESET；旧 OLED 的 `PB10/PB11` 也不再初始化。RGB蓝色改用同侧排针的`PB3`。

补光灯只在抓拍前短暂开启，抓拍完成立即关闭；不作为常亮夜灯。哭声确认后先生成本地事件，再抓拍，摄像头失败不能阻塞声音告警和 MQTT 告警。

## 5. 按键与调试排针

V2.0 实物上的 2x4 调试排针丝印包含两组：

- `5V, GND, DIO, CLK`
- `3V3, RST, TXD, RXD`

载板必须按实物方向放置对应 2x4 母座，不能使用旧版原理图推测方向。

| 功能 | 连接 | 行为 |
|---|---|---|
| KEY1 | RST 与 GND | 按下立即硬复位 H7 |
| KEY2 | ESP GPIO0 与 GND | ESP 正常运行时长按 5 秒清除 Wi-Fi 并进入 AP 配网 |
| CH340 | TXD/RXD/GND | 只调试 H7 的 USART1，不给系统供电 |

KEY1 不与普通 GPIO 连接，不依赖任务调度，因此固件卡死时仍可复位。H7 自带 IWDG 仍作为无人操作时的自动恢复手段。

## 6. 开发板上必须保留的占线

以下引脚即使固件暂时不用，也已经连接板载器件，载板不得分配给其他模块：

| 板载器件 | 占用引脚 |
|---|---|
| W25Q QSPI Flash | PB2, PB6, PD11, PD12, PD13, PE2 |
| MicroSD | PC8, PC9, PC10, PC11, PC12, PD2 |
| USB | PA11, PA12 |
| SWD | PA13, PA14 |
| 25MHz HSE | PH0, PH1 |
| 32.768kHz LSE | PC14, PC15 |
| 板载 K1/K2 | PE3, PC5 |
| CAMERA FPC | 第 4 节列出的 15 根信号线 |

特别禁止：不能再提出 `PD11/PD12/PD13` 的 SAI2 音频方案，也不能把 `PC4` 当作普通功能按键。

## 7. DMA 与内存预算

| 用途 | 资源 |
|---|---|
| 音频 SAI3 RX | DMA1_Stream0，DMA_REQUEST_SAI3_A |
| OV2640 DCMI | DMA2_Stream7，DMA_REQUEST_DCMI |
| TFLM tensor arena | AXI SRAM 512KB，现已全部预留 |
| 音频/UART循环DMA/环形缓冲/快照 | D2 SRAM 131456B |
| 240x240 RGB565相机帧 | D2 SRAM 115200B |
| D2 SRAM 剩余 | 48256B（约47KB） |
| 320x240 JPEG有界缓冲 | D3 SRAM 61440B |
| D3 SRAM 剩余 | 4096B，禁止再增加大对象 |

当前实现将RGB565和JPEG放在不同SRAM域，避免与音频DMA和TFLM arena重叠；总量已经接近D3上限，后续不得提高JPEG上限或在D3增加对象。照片按240原始字节分片，ESP MQTT缓冲为512B，不能把整张Base64图片拼成一个UART文本行。若实测320x240 JPEG经常超过60KB，应调低OV2640 JPEG质量或分辨率，不得盲目扩大缓冲。

## 8. 载板布局约束

1. H7 开发板放在中部，USB-C、CAMERA FPC、RST/BOOT 和 SD 卡槽周围留操作空间。
2. TFT 位于正面并直插开发板 DISPLAY FPC；载板只预留屏幕、排线和固定结构空间，不画 TFT 电气封装。
3. OV2640 位于外壳上部正面，通过原装 FPC 连接；排线不折死，不从 MQ-135 加热区经过。
4. INMP441 靠近前面板拾音孔，远离蜂鸣器、MQ-135、ESP 天线和 USB 电源线。
5. MQ-135 放在外壳边缘独立开孔处，与 DHT11、INMP441 和塑料结构保持距离，周围不得封闭积热。
6. DHT11 和 GP2Y1010 进气区域放在较冷的一侧，不能贴着 MQ-135。
7. GP2Y1010 金属传感器固定在外壳风道，适配板插在载板 1x4 母座；原装 6 芯线保留。
8. ESP-01 天线端朝 PCB 外缘，天线正下方和前方至少 15mm 不铺铜、不放 H7、TFT 金属件或传感器。

## 9. 上电前必须完成的三项实测

1. MQ-135模块使用5V供电，AO按用户的受控演示方案直连PA3，DO悬空。不得用打火机气体、高浓度烟雾或其他强刺激测试MQ；厂家标称AO最高约4V，直连超出3.3V的风险由该演示取舍保留。
2. 本项目GP2Y1010/1014适配板原理图和厂家说明已确认AO经过1:10分压，传感器最大约3.4V时AO约0.31V，可接PC1；首次实板仍记录正常空气原始值，确认没有接错针序。
3. 模块全部接齐、ESP 联网、TFT 刷新、OV2640 补光和蜂鸣器同时工作，连续运行 30-60 分钟，检查 H7 是否复位、ESP 是否掉线以及 3.3V 稳压区域是否异常发热。

这三项是接口验收，不是要求设备连续运行 24 小时。比赛前再做分时累计的多轮稳定性测试即可。
