# AI Hear PCB与外壳落地说明

## 文件

- `aihear-carrier-pcb-layout.svg/png`：120x90mm排母载板布局与禁布区。
- `aihear-enclosure-plan.svg/png`：150x115x65mm桌面外壳三视/分区方案。

只有以上两组`aihear-*`图和本文是最终工程方案。目录中的其他早期概念图若仍存在，不得用于画板或开孔。

## 从图到PCB

1. 在EDA中新建120x90mm双层板，先放H7两组2x20排母和四个固定孔。
2. 用卡尺测量每个实物模块的排针间距、板框和最高点；不要直接按商品图缩放。
3. 按布局SVG放置各模块排母，模块轮廓画到机械层，ESP天线区画15mm禁铜区。
4. 先铺GND，再布5V/3.3V宽线，最后布数字/ADC信号；不添加图中未列出的器件。
5. 导出1:1镜像纸样，把H7和全部模块真实插放一次，再生成Gerber。

## 从图到外壳

1. 先按150x115x65mm做低精度壳体，前盖单独打印。
2. 到货后实测TFT可视区、摄像头镜头/补光位置和FFC自然弯曲半径，再改前盖开孔。
3. MQ-135单独靠上排气；DHT11/GP2Y位于冷区；麦克风孔和蜂鸣器孔分置两侧。
4. USB-C、KEY1、KEY2留侧面操作孔；外壳内必须能拔出ESP和FFC。

这些图是布局和结构工程依据，不是可直接投板的Gerber或可直接打印的STL。唯一电气连接依据是 `docs/hardware_pin_plan.md`。
